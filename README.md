# Doce Ateliê — Site da Confeitaria Artesanal

Projeto da atividade de extensão **"Desenvolvimento Web Comunitário com IA e Git"**.
Este site institucional foi criado para um parceiro da comunidade local, uma confeitaria artesanal.

## Parceiro beneficiado
- **Nome:** Doce Ateliê *(trocar pelo nome real)*
- **Ramo:** Confeitaria artesanal (bolos, tortas, macarons e doces finos)
- **Local:** São Paulo/SP *(trocar pela cidade real)*

## Objetivo
Dar presença digital à confeitaria: mostrar os produtos e os preços, contar a história da marca e facilitar as encomendas pelo WhatsApp.

## ODS atendidas
- **ODS 8:** ajuda na digitalização de um pequeno negócio local.
- **ODS 9:** o site foi criado com ferramentas de desenvolvimento assistido por IA.
- **ODS 10:** leva tecnologia a um empreendedor que não teria recursos para contratar um site.

## Funcionalidades
- Página inicial com destaque visual e botão de encomenda
- Cardápio com produtos e preços
- Seção "Nossa história"
- Contato: endereço, horário e WhatsApp
- Layout que se adapta a celular e computador

## Ferramentas utilizadas
- **Lovable** (desenvolvimento assistido por IA)
- React + TanStack Start + Tailwind CSS
- Git e GitHub (versionamento)
- Hospedagem: Lovable / Vercel / Netlify

## Como rodar localmente
```bash
bun install
bun run dev
```
